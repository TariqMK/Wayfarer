Wayfarer
Principles

Stays on your computer

Works offline. No accounts, no telemetry, nothing sent. The one connection is the version check, to GitHub, when you select it.

One folder, fully portable

Trips and exports live in WayfarerData next to the app. Copy the app and the folder together to move or back up everything.

No installer

Download one file and open it. Wayfarer keeps none of your data in your user profile.

Features

One trip, three posters

Plan once in the editor. Choose a poster style and a light or dark appearance when you export.

Poster styles

The sample trip, drawn by Wayfarer's own poster code

Every type has its own line

Eleven entry types. Each one draws its own line on the route, like a rail map.

Plain text too

Export a text file, or select Copy to put the same itinerary on the clipboard.


        

      


      

        
Morning, afternoon, evening
Each day has three parts. Add entries to each.

        
Dates that follow on
Each new day gets the date after the previous day.

        
Drag to reorder
Move an entry to another part of the day, or drag a whole day.

        
Works without a mouse
Move up and Move down on entries, arrows on days, Ctrl+S to save.

        
Overnight entries
Mark a night train or flight that spans one night or more.

        
Undo a deletion
A deleted entry or day can come back for 6 seconds.

        
PDF in A4 pages
Long trips continue on more pages, cut between rows.

        
One PNG image
The whole poster as a single picture to share.

        
Light and dark
Choose the appearance per export. Use Light to print.

        
Unsaved changes
Wayfarer asks before it closes a trip you have not saved.

        
Check for updates
Select the version number. Nothing downloads or installs itself.

        
Plain JSON files
One file per trip, in a folder you can open and copy.

      

    

  


  

    

      
Download

      
Download Wayfarer

      
Free. One file per computer. Put it in a folder you can change, for example in Documents.

      

        
          
Windows
x64 · .exe

          
Builds are unsigned. If Windows shows a warning, select More info, then Run anyway. Needs WebView2, which Windows 11 includes.

        
        
          
macOS
Apple Silicon · .zip

          
Move Wayfarer.app out of Downloads first. Approve it once under System Settings, Privacy & Security.

        
        
          
Linux
x64 · .tar.gz

          
Needs GTK 3 and WebKit2GTK 4.1. Unpack it and open the Wayfarer file.

        
      

      
Do not put Wayfarer in Program Files or another protected folder. It can't save trips there. To build from source, follow Run from source in the README.
